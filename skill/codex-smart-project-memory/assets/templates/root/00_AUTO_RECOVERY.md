# 00 Auto Recovery

## New Session Recovery

1. Identify whether the task is global, project-specific, or unclear.
2. If unclear, read `00_SMART_ROUTER.md`.
3. If project-specific, read that project's `04_context_pack.md`.
4. If the user mentions old decisions or handoffs, read `05_conversation_memory.md`.
5. If concrete files are needed, read `07_asset_index.md`.

Never claim to remember full previous conversations unless the information exists in memory files.
